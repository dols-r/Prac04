| Логических ядер (Диспетчер задач) | 8 |

Да, предположение о том, что .NET видит именно логические процессоры подтвердилось.

#Часть 3
| Запуск | Режим | Итераций примерно за 1 секунду |
|-------:|------:|-------------------------------:|
| 1 | Debug | 47 992 499 |
| 2 | Debug | 48 947 421 |
| 3 | Debug | 48 836 541 |
| 4 | Release | 52 678 193 |
| 5 | Release | 55 222 983 |
| 6 | Release | 54 711 815 |
1. Результаты внутри одного режима отличаются несильно.
2. В режиме Release число итераций выше. Не совпало: думала, т.к. Debug полностью подробно выполняет программу, то у него число итераций будет выше.
Эксперимент показал различия сборки Debug и Release по "скорости". Не подтвердилось предположение о том, что Debug будет выполнять больше итераций из-за своего объёма сборки.
